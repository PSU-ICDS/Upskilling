# Tutorials and guides

Shorter how-to walkthroughs, cheat sheets, reference libraries, and written guides. Good when you want to solve a specific problem or skim an overview rather than commit to a full course. Ordered alphabetically by title.

### [AI at Penn State: Resource Library](https://ai.psu.edu/resources/resource-library)

**Level:** Beginner · **Modality:** Text · **Purpose:** Research, Productivity

Penn State's central, regularly updated library of AI guidance, tool comparisons, responsible-use information, and training links. A dependable place to check what is officially supported and recommended at the university.

**Reviews:**

- 07/2026 — **Penn State** — Highly Recommend. This covers AI tools provided by Central IT, and includes a summary of policies and where to get help.

### [AI-assisted spaced-repetition study workflow (Anki + ChatGPT + Codex)](https://apps.ankiweb.net/)

**Level:** Beginner · **Modality:** Text · **Purpose:** Learning Aid

Not a single tool but a workflow one fellow built for intensive self-study: read a textbook chapter, generate Markdown flashcards with ChatGPT, review them in the [Anki](https://apps.ankiweb.net/) spaced-repetition app, and use a local Codex agent to update and correct flashcards against notes over time.

**Reviews:**

- 07/2026 — **Justin Silverman** — Highly Recommend. Combined textbook reading, ChatGPT-generated flashcards, Anki spaced repetition, and a local Codex agent that kept flashcards updated and corrected. The broader lesson: AI can support individualized, iterative learning at scale, not just drafting or coding.

_Source: 2026 Summer Faculty Upskilling Reflection Lunch meeting notes._
