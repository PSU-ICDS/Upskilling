To suggest a repository, open a pull request, issue, or email per [CONTRIBUTING.md](../../CONTRIBUTING.md), and mention whether you would like it linked or incorporated as a submodule.

There are two ways we bring in a full repository. A maintainer will pick the right one with you.

**1. Link to it (default).** We list the repository here with the same entry format as everywhere else. Simple, always works, and the materials stay wherever the author keeps them.

**2. Incorporate it as a git submodule (for closely tied materials).** When it makes sense to pull a repository directly into this one, a maintainer adds it as a submodule under this folder. That keeps a pinned reference to the other repository without copying its files, and the original author keeps full control of their work. Maintainers: see the submodule notes in [CLAUDE.md](../../CLAUDE.md) and [the Git submodule documentation](https://git-scm.com/book/en/v2/Git-Tools-Submodules). Contributors do not need to do anything special, just tell us the repository URL and we will handle it.
