# Resources

This folder holds the selected learning resources, grouped by type. Pick a category below, or start with the featured list on the [repository home page](../README.md#start-here).

| Category | What you'll find |
|---|---|
| [Tutorials and guides](tutorials-and-guides/README.md) | Short how-to walkthroughs, cheat sheets, and written guides. |
| [Books and articles](books-and-articles/README.md) | Longer reading, papers, and reports. |
| [AI models](ai-models/README.md) | Notes on specific models and when to reach for each. |
| [AI tools and harnesses](ai-tools-and-harnesses/README.md) | Assistants, agents, IDEs, notebooks, and platforms. |
| [Videos and talks](videos-and-talks/README.md) | Recorded talks, lectures, and video series. |
| [Community repositories](community-repos/README.md) | Full GitHub repositories shared by Penn State colleagues. |
| [Courses](courses/README.md) | Structured, multi-module courses and certificate programs. |

## How to read an entry

Every entry has a linked title, a line of plain-text tags (Level, Modality, Purpose), and one or more reviews. Each review names a real person and gives a recommendation, often with a sentence on why. Some entries link to a detail page under [`details/`](../details) with more depth.

## How to add one

See [CONTRIBUTING.md](../CONTRIBUTING.md). There is a path for every comfort level with GitHub, including a pull request, an online form, a GitHub issue, or an email. Copy the [entry template](../templates/resource-entry-template.md), fill it in, and drop it under the right category.
