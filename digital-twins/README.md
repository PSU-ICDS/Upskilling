# Digital Twins Hub resources

The Digital Twins Hub bridges the physical and digital worlds by fostering collaboration among researchers, industry partners, and technologists. Its website is at [icds.psu.edu/research/hubs/digital-twins](https://icds.psu.edu/research/hubs/digital-twins/).

This page collects learning materials that members of the Penn State community have tried and found useful for virtual models of physical systems, sensor and data integration, real-time simulation, model validation.

## No entries yet

This hub is new to the repository and has no entries so far. That is an invitation, not a gap. If a course, tutorial, tool, book, or talk helped you get up to speed, please add it. One entry is enough to start the page, and a maintainer will set up the category page for you if it does not exist yet.

The [AI Hub](../ai/README.md) shows what a filled-in hub looks like.

## What goes here

Anything that helped you learn: a structured course, a short how-to guide, a tool you now use daily, a book worth the time, or a recorded talk that made an idea click. Entries can be beginner-level or advanced. Negative reviews are welcome too, since knowing what did not work saves colleagues time.

See the [category list](resources/README.md) for how entries are grouped.

## Add the first entry

You do not need to be an expert to contribute, and you do not need to be comfortable with GitHub. Full instructions are in [CONTRIBUTING.md](../CONTRIBUTING.html). In short:

- **Comfortable with GitHub?** Open a pull request against this hub's [resources folder](resources/README.md), using the [entry template](../templates/resource-entry-template.md).
- **Prefer a web form?** Open a GitHub Issue using the "Suggest a resource" template and choose this hub.
- **Rather not touch GitHub at all?** Email the details to `icds@psu.edu` with the subject line "ICDS Upskilling Learning Repository: Suggestion".

A title, a link, a couple of tags, and one sentence about how useful you found it is plenty.
