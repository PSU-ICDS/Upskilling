# Detail pages

Most resources are described in a few lines on their category page. When a reviewer wants to say more, the entry links here with a `_More info:_` line. Detail pages are shared across all five hubs, so each one names its hub at the top.

| Detail page | Hub | About |
|---|---|---|
| [Anthropic: Learn](example-detail-page.md) | Artificial Intelligence | A worked example showing the depth a detail page can have. |
| [PDF-to-Markdown converters](pdf-to-markdown-converters.md) | Artificial Intelligence | Tools for turning papers and reports into plain text for search, editing, and AI workflows. |

## Write one

Copy [templates/resource-detail-page-template.md](../templates/resource-detail-page-template.md), save it here with a descriptive filename (for example, `claude-code-getting-started.md`), and link to it from the resource's entry. See [CONTRIBUTING.md](../CONTRIBUTING.html).

A detail page is optional. A one-sentence review on the category page is a complete contribution on its own.
