# Templates

Copy-and-fill starting points for contributions. The same two templates serve all five hubs.

| Template | Use it when |
|---|---|
| [Resource entry template](resource-entry-template.md) | Adding any resource. This is the one almost everyone needs. |
| [Detail page template](resource-detail-page-template.md) | A resource deserves a longer write-up than a few lines. |

Filled-in entries live at `<hub>/resources/<category>/README.md`, for example `ai/resources/courses/README.md`. Detail pages live in [`details/`](../details/README.md).

New here? Start with [CONTRIBUTING.md](../CONTRIBUTING.html), which walks through the whole process, including paths that do not involve editing files at all.
